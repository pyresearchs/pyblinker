This folder contain pkl files for testing the major structure refactor. The pkl files are generated by the old code and will be used to compare with the new code to ensure that the refactor does not break any functionality. The pkl files are generated by running the old code on a sample dataset and saving the output in a pkl file. The new code will be run on the same sample dataset and the output will be compared with the pkl files to ensure that they are the same.

This folder will be deleted after the refactor is complete and all tests have passed.
